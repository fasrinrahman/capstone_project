# Capstone Project – ProjectFlow Dashboard

## Overview

ProjectFlow is a responsive task management dashboard built to simulate a real-world productivity tool. It allows users to create, manage, and track tasks efficiently with an intuitive UI and dynamic interactions.

This project reflects my learning journey in frontend development, focusing on building structured, maintainable, and user-friendly interfaces.

---

## ✨ Features

- 📊 Dashboard with task statistics (Total, In Progress, Completed, Overdue)
- ➕ Add new tasks with modal form
- 🔍 Search functionality
- 📂 Filter tasks by status (To Do, In Progress, Completed)
- 🔃 Sort tasks (Name, Date, Priority)
- 🎯 Priority-based task management
- 📱 Fully responsive UI (mobile + desktop)
- ⚡ Dynamic DOM manipulation using JavaScript

---

## 🛠️ Tech Stack
